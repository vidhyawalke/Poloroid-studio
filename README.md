# 📸 Polaroid Studio

An interactive, clean, and fresh digital Polaroid card generator inspired by Michelle Liu's *Polaroid Studio*. Built using React 18, Vite, and Tailwind CSS, this project is optimized for instant local execution and 100% free static deployment on Vercel.

---

## ✨ Features & Enhancements

- **Minimalist, Clean Design**: Bright, elegant dot-pattern background canvas centering focus completely on the camera card frame.
- **Physical Film Developing**: Uploaded images fade in from dark green with visual blur chemistry over 3 seconds, mimicking real physical polaroids.
- **Tactile Sound Engine**: Crisp mechanical camera clicks, tape tearing, and slide transitions programmatically synthesized in-browser using the Web Audio API (no external MP3 asset dependencies).
- **Aesthetic Frame Colors**: Swap frame styles between Cream White, Sage Green, Rose Pink, Sky Blue, and Warm Sand.
- **Washi Tape Overlay**: Toggle elegant translucent washi tapes (Peach, Sage, Sky, Amber) on the card with realistic stick sounds.
- **Image Cropper & Pan**: Drag the photo directly inside the polaroid viewport to pan, crop, and adjust alignment.
- **Live Sliders**: Easily adjust photo zoom, card rotation tilt, and text fonts (Reenie, Caveat, Kalam).
- **Date Stamp**: Autogenerated calendar stamp in Courier font (hideable).
- **PNG Download**: Instantly renders and compiles the card as an ultra-high resolution (3x scale) PNG using `html2canvas`, accompanied by a confetti reaction.

## 🚀 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vidhyawalke/Poloroid-studio.git
   cd Poloroid-studio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

---

## ☁️ Deploy to Vercel

This repository is optimized for Vercel out of the box as a static frontend SPA:

1. Import your **`Poloroid-studio`** repository into Vercel.
2. Click **Deploy** (no environment variables or server configuration needed!).
3. Get a fast, premium, live URL in seconds.
