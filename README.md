# AuraSnap Studio

## About
AuraSnap Studio is a web app for creating custom snapshot images. It offers a clean interface, photo upload with pan and zoom, caption fonts, frame colour picker, optional date stamp, PNG download, and share link copy.

## Features
- Clean UI
- Photo upload, pan & zoom
- Caption with selectable fonts
- Frame colour picker
- Date stamp option
- PNG download
- Share link copy

## Running locally
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open http://localhost:3000 in your browser.

## Deploy
Deploy to Vercel as a static site; no server configuration needed.
